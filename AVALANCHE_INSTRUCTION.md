# Инструкция по работе с Лавинным тестом (Avalanche Test)

Лавинный эффект — это свойство криптографического алгоритма (в частности, ГПСЧ), при котором небольшое изменение входных данных (например, смена одного бита ключа или зерна) приводит к значительному изменению выходных данных (последовательности).

## Как провести тест:

1.  **Подготовка данных**:
    *   Сгенерируйте первую битовую последовательность (файл А) с использованием вашего исходного ключа/зерна.
    *   Измените ровно один бит в вашем ключе/зерне.
    *   Сгенерируйте вторую битовую последовательность (файл Б) той же длины.

2.  **Запуск теста**:
    *   Запустите приложение: `streamlit run app.py`
    *   Выберите "Лавинный тест" в меню слева.
    *   Загрузите файл А в поле "Загрузить файл (Основная последовательность)".
    *   Загрузите файл Б в поле "Загрузить второй файл".
    *   Нажмите "Запустить выбранные тесты".

3.  **Интерпретация результатов**:
    *   Тест сравнивает биты на одинаковых позициях в обоих файлах.
    *   **Коэффициент лавины**: Процент бит, которые отличаются.
    *   **Идеальный результат**: 50% (0.5). Это означает, что изменение входа сделало выход непредсказуемо другим.
    *   **Диапазон**: Значения в диапазоне 45% - 55% обычно считаются приемлемыми.

## Проверочные файлы

В папке созданы два файла для проверки работы теста:
*   `sample_avalanche_1.txt`
*   `sample_avalanche_2.txt`

Эти файлы содержат случайные последовательности, которые должны показать хороший результат (около 50% различий).
