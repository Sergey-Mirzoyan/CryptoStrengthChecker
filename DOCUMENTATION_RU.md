# Документация: Программа Проверки Криптостойкости (Crypto Strength Checker)

## 1. Введение

**Crypto Strength Checker** — это мощный инструмент для анализа и визуализации криптографической стойкости псевдослучайных последовательностей. Программа позволяет генерировать последовательности с использованием различных алгоритмов (от клеточных автоматов до современных блочных шифров) и проверять их качество с помощью набора стандартных статистических тестов.

### Основные возможности:
*   **Мульти-генерация**: Поддержка широкого спектра генераторов псевдослучайных чисел (ГПСЧ).
*   **Визуализация**: Интерактивная визуализация работы алгоритма "Игра Жизнь" и лавинного эффекта.
*   **Комплексный анализ**: Встроенные тесты NIST SP800-22, Diehard, а также нейросетевой анализ.
*   **Гибкость**: Возможность настройки параметров генерации и тестирования.

---

## 2. Архитектура

Программа написана на языке **Python** с использованием фреймворка **Streamlit** для создания веб-интерфейса.

### Структура проекта:
*   `app.py`: Основной файл приложения, отвечающий за интерфейс и логику взаимодействия.
*   `generators/`: Пакет, содержащий реализации всех алгоритмов генерации.
    *   `base.py`: Базовый класс для всех ГПСЧ.
    *   `game_of_life.py`: Реализация ГПСЧ на основе клеточного автомата.
    *   `aes.py`, `magma.py`, `kuznechik.py`, `sm4.py`: Реализации блочных шифров в режиме счетчика (CTR).
    *   `bbs.py`: Генератор Блюм-Блюм-Шуба.
    *   `mersenne.py`, `lfsr.py`: Слабые генераторы для демонстрации.
*   `stats/`: Модули статистических тестов.
    *   `sp800_22_tests/`: Реализация тестов NIST.
    *   `DIEHARD/`: Реализация тестов Diehard.
*   `analysis.py`: Модуль для нейросетевого и базового статистического анализа.
*   `avalanche.py`: Модуль для расчета лавинного эффекта.

## 3. Генераторы Псевдослучайных Чисел (ГПСЧ)

Программа включает три категории генераторов:

### 3.1. Игра «Жизнь» (Game of Life)
Уникальный генератор, основанный на клеточном автомате Джона Конвея.
*   **Принцип работы**: Поле клеток эволюционирует по правилам "рождения" и "смерти". Случайность извлекается из состояния поля.
*   **Энтропия**: Начальное состояние (seed) формируется на основе системного времени, счетчиков процессора и хеширования координат, обеспечивая высокую непредсказуемость.
*   **Режимы границ (Boundary Modes)**:
    *   **Toroid (Тороид)**: Поле замкнуто само на себя (верх соединяется с низом, лево с правом). Обеспечивает бесконечную эволюцию без границ.
    *   **Fixed (Ограниченная матрица)**: Поле имеет жесткие границы. Клетки за краем считаются "мертвыми". Это вносит искажения у краев, что может влиять на статистику.
*   **Режимы извлечения битов**:
    *   *Flatten*: Все клетки поля выстраиваются в одну строку.
    *   *Best Line*: Выбирается строка с наибольшей энтропией (максимальным числом переходов 0->1).
    *   *Ternary*: Строки интерпретируются как троичные числа.

### 3.2. Криптостойкие (Cryptographically Secure)
Реализации современных стандартов шифрования в режиме генерации потока (CTR mode).
*   **AES (Advanced Encryption Standard)**: Американский стандарт (FIPS 197). Использует 128-битный блок и ключ.
*   **Magma (ГОСТ 28147-89)**: Советский и российский стандарт блочного шифрования. 64-битный блок, 256-битный ключ.
*   **Kuznechik (Кузнечик, ГОСТ Р 34.12-2015)**: Современный российский стандарт. 128-битный блок, 256-битный ключ.
*   **SM4**: Китайский национальный стандарт для беспроводных сетей. 128-битный блок и ключ.
*   **BBS (Blum Blum Shub)**: Классический криптостойкий генератор, основанный на сложности факторизации больших чисел. Медленный, но с доказанной стойкостью.

### 3.3. Слабые / Демонстрационные (Weak)
Добавлены специально для демонстрации того, что "случайный" не значит "криптостойкий".
*   **Mersenne Twister (MT19937)**: Стандартный генератор во многих языках программирования (включая Python `random`). Обладает огромным периодом, проходит многие стат. тесты, но **предсказуем**, если известно достаточное количество выходных данных (624 числа). Не подходит для криптографии.
*   **LFSR (Linear Feedback Shift Register)**: Линейный регистр сдвига с обратной связью. Очень быстрый и простой в реализации ("железный"), но абсолютно линеен и легко взламывается алгоритмом Берлекампа-Мэсси.

## 4. Статистические Тесты

Для проверки качества последовательностей используются:

1.  **NIST SP800-22**: "Золотой стандарт" тестирования ГПСЧ. Набор из 15 тестов, проверяющих различные аспекты случайности (частота, длинные серии, спектральный анализ и др.).
2.  **Diehard Tests**: Набор тестов Джорджа Марсальи. Включает специфические тесты ("Birthday Spacings", "Parking Lot"), хорошо выявляющие закономерности в слабых генераторах.
3.  **Нейросетевой Анализ**: Экспериментальный метод. Простая нейросеть пытается предсказать следующий бит последовательности. Если точность предсказания > 55% (существенно выше 50%), последовательность считается слабой.
4.  **Хи-квадрат (Chi-Square)**: Классический статистический тест на равномерность распределения битов и серий.
5.  **Лавинный Эффект (Avalanche Effect)**: Проверяет, насколько сильно меняется выходная последовательность при изменении входного ключа (seed) всего на 1 бит.
    *   *Идеал*: Изменение 50% бит выходной последовательности.
    *   *Визуализация*: В режиме "Game of Life" программа показывает два поля "До" и "После" и разницу между ними.

## 5. Руководство Пользователя

### Запуск
1.  Убедитесь, что установлены все зависимости (`pip install -r requirements.txt`).
2.  Запустите приложение: `streamlit run app.py`.

### Генерация последовательности
1.  В боковой панели (Sidebar) выберите **Generator Algorithm**.
2.  Введите **Seed** (или оставьте 0 для случайного).
3.  Настройте параметры:
    *   Для *Game of Life*: Размеры поля, количество шагов, режим границ (*Boundary Mode*), метод извлечения.
    *   Для остальных: Длина последовательности в битах.
4.  Нажмите кнопку **🚀 Generate (Сгенерировать)**.
5.  Результат появится в текстовом поле. Вы можете скачать его как файл.

### Тестирование
1.  После генерации (или загрузки файла в боковой панели) поставьте галочку **🧪 Test This Sequence (Проверить эту последовательность)**.
2.  Выберите нужные тесты (NN & Stat, NIST, Diehard).
    *   *Примечание*: Тесты NIST и Diehard могут занимать длительное время на больших последовательностях.
3.  Нажмите **▶️ Run Tests (Запустить тесты)**.
4.  Изучите результаты в появившихся блоках. Зеленый цвет означает успешное прохождение, красный — провал.

### Лавинный тест (Avalanche Test)
1.  Для *Game of Life*: Включите галочку **❄️ Avalanche Test Mode**. Программа автоматически сгенерирует две последовательности с разницей в 1 бит seed и покажет результат.
2.  Для внешних файлов:
    *   Загрузите первый файл в "Upload Binary File".
    *   Поставьте галочку "Avalanche Test" в боковой панели.
    *   Загрузите второй файл в "Upload Second File".
    *   Нажмите "Run Analysis".
