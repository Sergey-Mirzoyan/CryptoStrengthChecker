# Инструкция по анализу криптостойкости (Нейросетевой и Статистический методы)

В данном приложении реализованы два подхода к анализу криптографической стойкости псевдослучайных последовательностей: **Побитовый (Bitwise)** и **Блочный (Blockwise)** анализ. Эти методы оценивают, насколько предсказуемой является ваша последовательность.

---

## 1. Как запустить проект

1. **Установите зависимости:**
   Для работы приложения требуются библиотеки, указанные в файле `requirements.txt`. Выполните команду в терминале (в папке проекта):
   ```bash
   pip install -r requirements.txt
   ```
2. **Запустите веб-приложение:**
   Приложение построено с использованием фреймворка Streamlit. Для запуска выполните:
   ```bash
   streamlit run app.py
   ```
3. **Откройте приложение в браузере:**
   Обычно оно автоматически открывается по адресу `http://localhost:8501`.

---

## 2. Описание методов работы

### Побитовый анализ (Bitwise Analysis)
В этом методе предсказание выполняется **по одному биту** на каждый шаг.
- **Комбинированный метод оценки (MLPClassifier):** Модель анализирует окно из заданного количества бит и пытается предсказать **один следующий** (или предыдущий) бит. Точность рассчитывается на основе множества попыток угадать этот один бит на разных позициях.
- **Статистический анализ (Хи-квадрат):** Строится распределение частот для одиночных битов, следующих за определенным паттерном (окном). Затем с помощью критерия согласия Пирсона (Хи-квадрат) оценивается, насколько распределение следующего бита отличается от случайного.

### Блочный анализ (Blockwise Analysis)
В этом методе предсказание выполняется сразу для **целого блока бит**.
- **Комбинированный метод оценки (MLPRegressor):** Модель авторегрессионно (по цепочке) предсказывает сразу последовательность бит, равную размеру окна. Оценивается, насколько точно весь предсказанный блок совпал с фактическим.
- **Статистический анализ (Хи-квадрат):** Оценивается частота появления целых блоков бит после заданного паттерна. Этот подход выявляет более длинные и сложные закономерности в последовательности.

## 3. Инструкция по использованию

### Шаг 1: Подготовка данных
1. Подготовьте бинарную последовательность (состоящую только из `0` и `1`), которую вы хотите проанализировать. 
2. Сохраните её в текстовый файл (например, `.txt` или `.bin`).
   - *Альтернативно: вы можете сгенерировать последовательность прямо в приложении, используя встроенные генераторы (Game of Life, AES, BBS и др.), и нажать "Проверить эту последовательность".*

### Шаг 2: Настройка и запуск
1. В боковом меню (или в настройках тестирования) укажите **Размеры окна (Window Sizes)** через запятую, например: `8, 16, 32`. Чем больше окно, тем более длинные зависимости пытается найти алгоритм (но это требует больше времени на вычисления).
2. Выберите файл для загрузки в поле **Основная последовательность**.
3. Убедитесь, что включен чекбокс **"Нейросетевой и Статистический (Хи-квадрат)"**.
4. Нажмите кнопку **"Запустить выбранные тесты"** (или "Запустить тесты" для сгенерированной последовательности).

### Шаг 3: Интерпретация результатов
После завершения анализа результаты появятся на экране. Они разделены на две вкладки: **Побитовый анализ** и **Блочный анализ**.

В каждой вкладке представлены следующие показатели:

**🧠 Комбинированный метод оценки:**
- **Точность (Accuracy):** Доля верно угаданных бит (в побитовом) или совпадений в блоках (в блочном). 
  - *Идеал:* около 50% (0.50). 
  - *Вывод:* Если точность **≤ 55%**, последовательность считается **СТОЙКОЙ**. Если больше — обнаружены закономерности.
- **Проанализировано бит:** Количество предсказаний, сделанных сетью для формирования оценки.

**📊 Статистический анализ:**
- **P-значение (P-Value):** Вероятность того, что найденные отклонения случайны. 
  - *Идеал:* Выше 0.05.
  - *Вывод:* Если P-значение **> 0.05**, гипотеза о случайности принимается (последовательность **СТОЙКАЯ**). Если **≤ 0.05**, последовательность предсказуема (**СЛАБАЯ**).
- **Детальная таблица:** Вы можете развернуть таблицы, чтобы посмотреть точность и p-value для каждого конкретного размера окна и направления (вперед/назад).

---

## 4. Выводы
Использование обоих методов (побитового и блочного) позволяет провести глубокий и всесторонний анализ. 
- Побитовый анализ отлично справляется с нахождением коротких, локальных зависимостей.
- Блочный анализ помогает выявить глобальные структурные уязвимости генератора псевдослучайных чисел, когда части последовательности повторяются целыми фрагментами. 

Для признания генератора надежным, тесты в **обеих вкладках** должны показать результат **СТОЙКАЯ (STRONG)**.
